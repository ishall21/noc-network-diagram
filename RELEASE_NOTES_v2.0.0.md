# NOC Network Diagram Studio v2.0.0

**Release type:** Project rename / major release  
**Tag:** `v2.0.0`

## What's changed
- Renamed the project from DETCONNECT Network Diagram Studio to NOC Network Diagram Studio.
- Repository slug is now `noc-network-diagram`.
- Updated the GitHub Pages URL to `https://ishall21.github.io/noc-network-diagram/`.
- Updated the default topology title and exported SVG, PNG, and JSON filenames.
- Retained the editable topology canvas and supplied MikroTik logo node.

## Publish
Create the repository `ishall21/noc-network-diagram`, upload the project files to the repository root, enable GitHub Pages from `main` / root, then push the tag `v2.0.0` to trigger the included GitHub Actions release workflow.
