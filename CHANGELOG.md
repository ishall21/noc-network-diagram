# Changelog

## v2.0.0 — 2026-10-14
- Renamed the project and repository slug from `detconnect-network-diagram` to `noc-network-diagram`.
- Updated user-facing branding and exported file names to NOC Network Diagram.
- Updated GitHub Pages and release instructions for `ishall21/noc-network-diagram`.


## v1.2.0 — 2026-10-12
- Replaced the text-only MikroTik-inspired node with the user-provided logo image.
- Removed the white background from the supplied logo and embedded it into the application for portable SVG/PNG exports.


## v1.1.0 — 2026-10-12
- Added a selectable MikroTik Router node with a MikroTik-inspired wordmark treatment.
- New nodes default to the MikroTik Router style for faster ISP topology diagramming.
- Added the MikroTik node type to the selected-node editor.


## v1.0.0 — 2026-10-12
- Initial public release.
- Added editable SVG topology canvas with starter ISP / IXP topology.
- Added draggable nodes, node properties, and connection editing.
- Added JSON import/export and SVG/PNG export.
- Added GitHub Pages deployment instructions.
